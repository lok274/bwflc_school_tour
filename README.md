## 相簿上傳（v160）

旅途回憶 → 相簿 → 上傳相片，可選全部或已確定勾選的相片，每批最多 30 張。準備後核對收相人 bwc-ykl@bwflc.edu.hk，輸入收相人提供的固定上傳碼，再按「確認上傳」。截止為香港時間 2026-11-09 23:59。相片保留於本機，僅傳送重新輸出的 JPEG，不附加身份、GPS 或打卡資料。

失敗請保留視窗，用同一上傳碼手動重試；系統先核對進度並跳過已儲存相片。關閉／離頁會失去續傳資料，不能撤回 Google 已接收的寫入，請收相人先核對 Drive 後才重新選取。本機、離線、診斷及預演不會真正上傳。固定碼只在接收器設定，不能加入程式碼、網址或瀏覽器儲存。

相片傳輸使用同一收相盒的 JSON 回覆，不依賴隱藏框架；表單及框架連線仍禁止。每次請求最多等候 120 秒，逾時不等於 Google 未儲存，請先用原視窗手動重試核對進度。
