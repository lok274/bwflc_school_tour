
一個繁體中文、手機優先、可安裝及離線使用的 PWA。提供三日行程、五個景點導覽、GPS 個人打卡、紀念相片及旅程卡。
選單為「首頁、行程、旅途回憶」；準備頁、內建清單、個人提醒及進度環已移除，舊 `#prepare` 網址會顯示首頁。既有打卡及相片保留。
首頁提供自願訂閱的手機通知。旅程相片和打卡繼續只保存在裝置內；原始 GPS 座標不會保存，通知訂閱另行管理。iPhone 須先把 App 加入主畫面。

正式景點頁及 `device-test.html` 都可重複拍照累積相片。正式景點須先打卡；測試相機毋須打卡，使用獨立測試儲存。正式回憶頁以下載為主要操作：準備完成後，一張下載 JPEG，多張下載 ZIP（須解壓），手機分享放次要位置，檔名及逐張下載在「更多選項」每頁最多十二項。下載可能位於「下載」或「檔案」，網頁不能保證直接存入相簿；App 內副本仍會保留。HEIC／HEIF 仍須先轉成 JPEG。裝置測試頁維持原有操作。

推送後台已設定，老師由[公告管理頁](https://bwflc-school-tour-push.bwflc-school-tour-lok274.workers.dev/admin)登入及發送公告，操作說明見 [push-backend](push-backend/README.md)。使用者已確認 Android 手機收到測試通知；iPhone 尚未實測。`npm test` 驗證前台，`npm run test:push` 驗證後台，`npm run build` 只整理可發布的前台資產。

### 旅途回憶

底部「旅途回憶」主頁最多顯示六個景點相簿封面（最新相片、站名、張數），手機兩欄，平板／桌面三欄。點封面開相簿，新至舊排列，每頁十二張；勾選可跨站及跨頁保留，主頁提供「下載全部」及「下載已選」，相簿可下載、全選或清除本站勾選。點縮圖看完整大圖並切換照片，按「製作單張旅程卡」才展開選填 80 字感想。返回／Escape 回上一層，關閉回主頁並恢復焦點及位置。既有相片毋須搬移；取消一站打卡會刪除本站 App 內全部相片，請先下載需要保留的回憶。

完成五個必需景點打卡後，可在回憶頁每站各選一張，生成 1080×1350 PNG 旅程合成卡。佛教黃鳳翎中學毋須打卡或拍照，可自選加入第六張學校相片，也可撤回；學校不能代替必需景點。卡片直向兩欄三排，完整保留相片邊緣，五張時最後一格顯示回憶寄語。完成打卡不代表已有相片：缺照時只列必需景點、補拍入口及原因；選齊五個景點才啟用下載。讀取中或失敗顯示讀取提示，不當成缺照。姓名最多 40 字、班別最多 20 字，均選填，只在目前頁面及本機圖片使用，不寫入儲存、不上傳、不加入檔名；離頁（包括補拍）或重載後須重新填寫及選取。合成卡選取與普通匯出互不影響。主頁保留進度、缺照補拍指引及製卡入口；合成卡視窗只有六個選圖位置，按位置再開該站分頁縮圖。關閉視窗保留選圖及文字草稿，確認或匯出時暫時收起回憶視窗，取消會返回原畫面。只為目前顯示的封面／縮圖／已選照片建立預覽網址，換頁後釋放不用的網址。離線快取 v58；儲存格式不變。
