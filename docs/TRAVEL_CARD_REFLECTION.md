# 旅程卡感想文字

每張相片的旅程卡區提供「感想文字（選填）」，最多 80 字。留空沿用原版面；填寫後會在 1080×1350 PNG 加上「我的感想」。換行與空白會整理成單一空格，再按卡片寬度自動換行，不截斷感想。下載前的確認會說明文字也會出現在卡上。

每張相片的草稿分開，只暫留在目前頁面。勾選相片或同頁重畫保留草稿；離頁、重新載入、取消打卡或清除資料會清除。沒有新增上傳或儲存資料欄位。

輸入限制、畫面計數及匯出驗證均按 Unicode 碼點計算，單個 🙂 算一字，組合表情可能包含多個字元。貼上超長文字時，欄位與草稿一併保留首 80 字。同頁重畫會恢復感想欄的焦點及游標；中文輸入法組字期間，重畫延至組字完成，避免中斷輸入。

本版本包含一鍵下載全部功能，使用既有 GitHub Pages 測試、建置及部署流程。
